== Description ==

Plugin to add additional functionality.

= Key Features =

* **FAQs:** adds FAQs section and structured data via CPT and shortcode for FAQ.
* **Projects:** adds Project/Portfolio section via CPT and shortcode sliders for Project.
  * 2 layouts for sliders
  * grid view for projects and filter them by category.
  * can mark projects as **featured** and use them for slider via shortcode.

== Requirements ==

- PHP 8.3+

== Installation ==

1. Upload the `nice-simple-vp` folder to the `/wp-content/plugins/` directory.
2. Ensure your server is running **PHP 8.3** or higher.
3. Activate the plugin through the 'Plugins' menu in WordPress.
4. Place the shortcode on any page.

== Usage ==

= Available Shortcodes =
* `[show_projects]`
* `[featured_projects_slider]`
* `[fancy_portfolio_slider]`
* `[show_faq]`
* `[show_faq_table]`
